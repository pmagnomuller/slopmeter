How it counts. One snapshot per UTC day: the last first-parent commit on the branch that day. Every file in that tree is classified as production (source code: .go .py .ts .sql .sh .tf …), test (tests/ dirs, _test.go, test_*.py, .spec/.test, .feature, mocks & fixtures) or ignored (docs, config, JSON/YAML, lockfiles, vendored, generated). Lines are counted exactly from the blob — nonblank means whitespace-only lines are dropped, comments stay. Daily movement uses git log --numstat --first-parent, so a merged PR lands as one day's change. The slop score is the attention-gap model: weighted lines added vs. human commit budget + test lines written; lower is better.
